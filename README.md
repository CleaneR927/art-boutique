# Pet-проект "Art Boutique"

**Стек технологий**: React, MobX, SCSS, JS, HTML, ESLint, Prettier

**Описание работы приложения**: Проект представляет собой магазин-витрину, там пользователь может посмотреть портфолио работ и информацию об авторе, чтобы потом через мессенджеры с ним списаться. В будущем будет настроен Api, который позволит регистрироваться пользователям в это приложении (почта, логин, пароль) и авторизовываться (логин, пароль). Любой пользователь сможет на главной странице познакомиться с кратким портфолио работ и автором. Авторизованного пользователя будет проверять логика, если это админ, то он сможет в личном кабинете видеть список авторизованных пользователей за все время и данные о них. Если авторизовался не админ, то он сможет посмотреть дополнительно портфолио работ, личного кабинета не будет.

## Структура проекта:

Данное приложение использует в своей основе архтиектурную методологию FSD (Feature-Sliced Design) длясоздания каркасов интерфейсных приложений.

- src/ - исходные файлы проекта.
- src/assets/: Хранит статические ресурсы, такие как изображения и шрифты.
- src/entities/: Определяет структуры данных, используемые в приложении.
- src/features/: Содержит модули, каждый из которых отвечает за определенную функциональность приложения.
- src/pages/: Каждая страница приложения представлена отдельным компонентом, что упрощает навигацию и управление контентом.
- src/shared/: Содержит общие ресурсы, такие как компоненты, стили, данные и утилиты, которые могут быть использованы в разных частях приложения.
- src/stores/: Хранит модели состояний (сторы), ответственные за управление различными аспектами вашего приложения, такими как аутентификация, регистрация и другие функциональности.
- src/widgets/: Содержит переиспользуемые компоненты, такие как заголовок и подвал.
- App.js: Главный компонент, который объединяет все страницы и компоненты.
- index.js: Точка входа, где приложение монтируется в DOM.

Вспомогательные файлы приложения:

- .babelrc - конфигурация babel
- .gitignore - файл gitignore, включающий ненужные файлы при пуше в репозиторий
- .prettierrc - конфигурация prettier
- config-overrides.js - конфигурация модифицируемая с помощью функции override, чтобы добавить поддержку для обработки LESS-файлов
- eslint.config.js - конфигурация eslint

## Установка и запуск приложения

Для установки и запуска проекта необходимо выполнить команды для установки зависимости и запуска проекта в режиме разработки, соответственно.

```
npm install
npm run start
```

или

```
yarn
yarn start
```

## Сервер

Копируем .env.example в .env

```
cp .env.example .env
```

## Сборка

Для сборки проекта в продакшн необходимо выполнить команду сборки в режиме разработки.\
Для данного проекта нет ограничений по использованию пакетного менеджера, поэтому можно использовать также YARN или PNPM.

```
npm run build
```

или

```
yarn build
```

## Системные требования

На данных версиях производилась разработка, тестирование и запуск приложения в продакшн.

- Node.js >= 20.15.0
- npm >= 10.9.2
